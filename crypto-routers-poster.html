РИС. 1Защищённый канал между узлами связи
Криптомаршрутизатор (криптошлюз, VPN-шлюз) шифрует трафик на входе в канал связи и расшифровывает на выходе — противник видит только шифротекст
01Основные функции
  • ШифрованиеТрафика по ГОСТ Р 34.12-2015 («Кузнечик», «Магма»)
  • ИмитозащитаКонтроль целостности: подмена данных обнаруживается
  • АутентификацияОбмен только между узлами с действующими ключами
  • Межсетевое экранированиеФильтрация трафика и маршрутизация
  • Скрытие структуры сетиАдреса и состав узлов не видны из канала

03Обращение с ключевыми документами

ЗАПРЕЩАЕТСЯ:

  1. Передавать и копировать ключевые носители
  2. Оставлять ключевые носители без присмотра
  3. Вскрывать опечатанную аппаратуру
  4. Изменять конфигурацию без разрешения начальника

ОБЯЗАН:

  1. Хранить ключевые документы в опечатываемом хранилище
  2. Вести учёт ключевых носителей
  3. Соблюдать установленный порядок смены ключей
  4. О компрометации ключей доложить немедленно
