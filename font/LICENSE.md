# Права на шрифт Gryadka

Права на шрифт и на шрифт Kapelka принадлежат заказчику. Условия использования определяются письмом или договором с правообладателем.

В таблице имён шрифта указано: «Copyright 2026 Gryadka Project Authors. All rights reserved.» Перед выпуском замените эту строку на реальное название правообладателя.
Для этого измените константу `COPYRIGHT` в `build_gryadka.py` и пересоберите файлы командой `python3 build_gryadka.py`.

Если шрифт нужно открыть для свободного использования, один из стандартных вариантов — лицензия SIL Open Font License 1.1. Она разрешает коммерческое использование и распространение, но запрещает продавать сам шрифт отдельно. Выбор лицензии остаётся за правообладателем.

Шрифт нельзя продавать и распространять вместе с файлами других шрифтов, например Villula. Файл Villula в проект не входит.
